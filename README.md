# ChatGPT Plugin Marketplace

Personal marketplace maintained by **wyr-zal**.

## Included plugins

1. Analyze
2. Deep-interview
3. Deepsearch
4. Design-taste-frontend
5. Image-to-code
6. Visual-verdict
7. Ui-ux-pro-max
8. DeepTutor Personal — hardcoded to `https://deeptutor.cliproxy.com.cn`
9. DeepTutor — portable workflow-only version without a hardcoded backend

## Import into ChatGPT

Use this repository URL in **Plugins → Add → Import marketplace**:

`https://github.com/wyr-zal/chatgpt-plugin-marketplace`

Use branch `main`. Leave the marketplace path blank; the manifest is at `.agents/plugins/marketplace.json`.

## Updates

Commit updates to `main`, then use **Sync now** for the marketplace in ChatGPT.
